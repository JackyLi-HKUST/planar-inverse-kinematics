1INVERSE FUNCTIONS AND INJECTIVITY逆函數與單射

A function can be reversed as a function exactly when outputs identify inputs uniquely.只有當輸出能唯一識別輸入，函數才能被反轉成另一個函數。

f(A)

Image像

All outputs actually reached:真正被取得的所有輸出： {f(x):x∈A}.

f⁻¹({y})

Preimage原像

Every input mapping to y:所有被映至 y 的輸入： {x∈A:f(x)=y}.

1–1

Injective單射

f(a)=f(b) ⇒ a=b.

onto

Surjective滿射

f(A)=B.

Not injective非單射
Injective, not onto單射但非滿射
Bijective雙射

The left map cannot have an inverse function because one output would need two inverse values. The middle map has an inverse on its image f(A), but not on all of B. The right map has an inverse B→A.左圖不能有逆函數，因為同一輸出需要對應兩個逆向值。中圖在像 f(A) 上有逆函數，但不能把逆函數定義於整個 B。右圖則有逆函數 B→A。

THEOREM 1定理 1

Inverse on the image ⇔ injective像上存在逆函數 ⇔ 單射

Let f:A→B. There exists a function g:f(A)→A satisfying g(f(x))=x for every x∈A if and only if f is injective.

設 f:A→B。存在函數 g:f(A)→A，使所有 x∈A 均滿足 g(f(x))=x，當且僅當 f 是單射。

Necessity (⇒)必要性（⇒）
  1. Assume an inverse g:f(A)→A exists.假設逆函數 g:f(A)→A 存在。
  2. Let a,b∈A and suppose f(a)=f(b).任取 a,b∈A，並假設 f(a)=f(b)。
  3. Apply g to both sides:對兩邊同時套用 g： g(f(a))=g(f(b)).
  4. Because g is an inverse, a=b. Hence f is injective.由於 g 是逆函數，所以 a=b。因此 f 是單射。
Sufficiency (⇐)充分性（⇐）
  1. Assume f is injective.假設 f 是單射。
  2. For each y∈f(A), at least one x∈A satisfies f(x)=y, by the definition of image.對每個 y∈f(A)，依像的定義，至少存在一個 x∈A 使 f(x)=y。
  3. Injectivity makes that x unique.單射性保證這個 x 是唯一的。
  4. Define g(y) to be this unique x. Then g is a well-defined inverse on f(A).定義 g(y) 為該唯一的 x，則 g 是 f(A) 上定義良好的逆函數。 □
Codomain note.到達集註記。 To define f⁻¹ on all of B, f must also be surjective; equivalently, f must be bijective. A set-valued preimage relation always exists, but it is an ordinary function only when every relevant preimage is a singleton.若要把 f⁻¹ 定義在整個 B 上，f 還必須是滿射；也就是說 f 必須是雙射。集合值的原像關係永遠可以定義，但只有每個相關原像都是單點集時，它才是普通函數。

2THE ROBOT AS A MAP把機械臂寫成映射

The global inverse fails because the forward map is generically two-to-one.整體逆函數不存在，因為正向映射在一般情況下是二對一。

F:(ℝ/2πℤ)2→ℝ2
F(θ1,θ2)=[L1cosθ1+L2cos(θ1+θ2)L1sinθ1+L2sin(θ1+θ2)]

Writing each angle modulo 2π identifies configurations that differ only by full rotations. The domain is therefore a torus, not the whole plane ℝ² of raw angle numbers.

把每個角度視為模 2π，等同於把只相差完整圈數的姿態視為同一個姿態。因此定義域是環面，而不是原始角度數對組成的整個平面 ℝ²。

q₊=(θ₁⁺,θ₂⁺)elbow-up configuration肘部向上姿態
F(q₊)= T =F(q₋)
q₋=(θ₁⁻,θ₂⁻)elbow-down configuration肘部向下姿態

For an interior reachable target T, q₊≠q₋ but F(q₊)=F(q₋). Therefore F is not injective, so Theorem 1 rules out a single global inverse function. IK must instead return the preimage set F⁻¹({T}).對於可達區域內部的目標 T，q₊≠q₋，但 F(q₊)=F(q₋)。所以 F 不是單射；依定理 1，單一整體逆函數不存在。IK 應返回的是原像集 F⁻¹({T})。

The Jacobian explains local invertibility and singular boundaries.Jacobian 解釋了局部可逆性與邊界奇異點。

This section uses partial derivatives and the multivariable inverse function theorem. It is not needed for Theorem 2, but it reveals why the two IK branches are smooth away from the boundaries.

這一節需要偏微分與多變量逆函數定理。它不是定理 2 的必需工具，但能解釋為甚麼離開邊界後，兩個 IK 分支都是光滑的。

DF(θ1,θ2)=[−L1sinθ1−L2sin(θ1+θ2)−L2sin(θ1+θ2)L1cosθ1+L2cos(θ1+θ2)L2cos(θ1+θ2)]

The determinant is non-zero. The inverse function theorem gives a unique smooth local inverse near that configuration.行列式非零。逆函數定理保證該姿態附近有唯一、光滑的局部逆函數。

sinθ₂=0

Globally, F is not injective. After restricting to either sign branch, however, it becomes a smooth bijection onto the open annulus. IK is therefore best understood as two inverse branches, not one global inverse.整體上 F 不是單射。但當我們把定義域限制在任一符號分支上，它就會成為映至開圓環的光滑雙射。因此 IK 應被理解為兩個逆分支，而不是一個整體逆函數。
