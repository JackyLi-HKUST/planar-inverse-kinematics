04 · ABOUT THIS PROJECT04 · 關於本專題

Made to make inverse kinematics understandable.把逆運動學變成看得見、想得通的數學。

Planar Inverse Kinematics is an interactive, bilingual mathematical study of existence, multiplicity and inverse maps for a two-link planar manipulator.

《平面逆運動學》是一個雙語互動數學專題，以雙連桿平面機械臂研究解的存在性、多解性與逆映射。

CREATED BY製作者Jacky Li ↗
COURSE課程MATH3900 · Communicating Mathematics to the Public
COURSE INSTRUCTOR課程導師Prof. Shing-Yu Leung ↗梁承裕教授 ↗

BUILT WITH使用技術

Small, transparent and made for the open web.輕量、透明，為開放網頁而製作。

The site has no framework, package manager or build step. Every page can be opened locally and the same files can be published directly with GitHub Pages.

網站不使用框架、套件管理器或建置程序。每個頁面都可直接在本機開啟，同一套檔案亦可直接發佈至 GitHub Pages。

Mathematical basis數學基礎

The derivations use the Pythagorean theorem, triangle inequality, circle intersections, the law of cosines, trigonometric identities, injectivity and the multivariable inverse function theorem. Definitions and proofs are developed within the site.

推導使用勾股定理、三角不等式、圓的交點、餘弦定理、三角恆等式、單射及多變量逆函數定理；相關定義與證明均在網站內逐步建立。
